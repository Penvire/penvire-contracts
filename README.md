# Penvire contracts

> **Status:** early development, not ready for production use.

OpenAPI, AsyncAPI and Avro contracts between the Penvire services and clients.

## What goes here

- API definitions for every Penvire service
- Event schemas
- The pipeline that validates contracts and publishes them as versioned packages

Integrations and third-party clients can build on these packages. The Apache-2.0 license keeps that free of copyleft obligations.
